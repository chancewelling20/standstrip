# Stand Strip (Fabric 1.21.11, client-side)

Module 1 of the loot mod. Run `/standstrip` in game to toggle it.
While on, it takes every item off armor stands within range, even through walls.

Build: push to GitHub, open the Actions tab, download the `standstrip-jar` artifact.
Or locally: `gradle build` (Java 21), jar lands in `build/libs/`.
Requires Fabric Loader 0.18.1+ and Fabric API for 1.21.11.
